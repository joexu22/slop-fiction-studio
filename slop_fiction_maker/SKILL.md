# Slop Fiction Video Maker — AI Skill

## What it does
Given a topic (or "surprise me"), this skill produces a complete, ready-to-upload
2-5 minute cultivation slop fiction episode:

1. Generates a campy, tropey xianxia short story script (Gemini).
2. Breaks it into narrative beats with over-the-top narration lines.
3. Chooses a bombastic narrator persona for variety.
4. Creates strong Ghibli + cultivation visual prompts.
5. Generates one short independent video **per beat** (dialogue lines are in the
   prompt so native Veo audio has the characters speaking). All the per-beat clips
   are then concatenated in post-production into the final long episode. This is
   the practical approach now that extension chains are limited to ~30 s total.
6. Currently uses Veo's native audio (ambient sound + effects generated by the model).
7. Generates a matching thumbnail (Ghibli-style still).
8. Writes clickbaity-but-on-brand title + description + tags.
9. (Optional) Uploads directly to YouTube.

**Note on Audio (default):** Dialogue is written explicitly by the script generator. These lines are passed into the Veo video prompts, so the characters speak them using Veo's native audio generation (`generate_audio=True`). No separate TTS narrator is created by default. This is the intended one-shot hands-off flow.

You can still opt into the old external over-the-top narrator track with `--with-custom-narration` (or the equivalent Python flag). See README.md "Audio" section for details.

The output is "slop" by design — we ask the models to do their best on the
Ghibli-cultivation aesthetic, but we celebrate the beautiful imperfections,
motion weirdness, and uncanny moments that current Veo produces.

## How to invoke (from chat / agent / MCP)
```python
from slop_fiction_maker.generate_episode import generate_slop_episode

result = generate_slop_episode(
    topic="a young outer sect disciple accidentally activates an ancient
           demon-slaying sword that starts talking to him",
    target_duration_seconds=180,   # ~3 minutes
    upload_to_youtube=False,       # set True after credentials are configured
)

print(result.final_video_gcs_uri)
print(result.youtube_url)  # if uploaded
```

Or from the command line:
```bash
python -m slop_fiction_maker.generate_episode \
  "a fallen genius re-cultivates using a forbidden bloodline technique" \
  --duration 240
```

For pure surprise slop:
```bash
python -m slop_fiction_maker.generate_episode --random
```

An agent (Gemini CLI, Claude, etc.) can call the Python entrypoint or a future
MCP tool wrapping it. The skill is intentionally "one generation, one shot".

## Core Design Decisions (per-beat generation + post-stitch assembly)
- Traditional per-scene cut + new generation every 4-8s forces the model to
  re-invent characters and motion every time → drift and inconsistency.
- Veo extension chains are limited to roughly 30 seconds. We therefore generate
  one short independent clip **per beat** (the script writes explicit dialogue
  for each beat; the lines are embedded in the prompt so native audio contains
  the characters speaking).
- All per-beat clips are concatenated with ffmpeg at the end to produce the
  final long episode. This is the reliable way to get 2-5 minute videos.
- The agent/MCP controls high-level decisions (target length, custom narration
  overlay, etc.). Per-beat reference images or style can be added later.

## Output artifacts (per run)
New runs use a clean, dated + serialized layout (gitignored):

```
slop_fiction_maker/output/
  YYYY-MM-DD/
    NNN-short-slug/
      clips/          # per-beat or extension-step clips (with native audio)
      audio/          # only when --with-custom-narration
      final/          # the deliverable .mp4(s)
      script.json
      metadata.json
      thumbnail.png
```

All final media is also uploaded to GCS via the studio's `store_to_gcs` and can be recorded in Firestore. The entire `output/` tree is deliberately **not committed** (see root `.gitignore`).

## Dependencies
This skill lives inside the `slop-fiction-studio` repo and re-uses:
- `models.veo` (the best current `generate_video` + extension support)
- `models.gemini` (scripting, prompt crafting, thumbnail)
- `common.storage` (`store_to_gcs`)
- FFmpeg patterns adapted from the excellent story-generator skill
  (voice-first timing, speed-fit guardrails at 1.25x, normalization, concat)

It does **not** require the Go MCP binaries to run (it calls the Python model
layer directly), but it is designed to be wrapped as an MCP skill later.

## Philosophy
> "The slop is the point."

We are not trying to make perfect cinema. We are making delightful, absurd,
over-the-top cultivation slop that embraces what the current generative models
do well and what they do strangely. The automation exists so the human can
focus on coming up with the next ridiculous premise and then go touch grass
while the silicon dream-engine forges another scripture.
